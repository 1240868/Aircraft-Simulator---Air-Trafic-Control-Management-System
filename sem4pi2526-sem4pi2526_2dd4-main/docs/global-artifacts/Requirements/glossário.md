# Glossário — Domain Model DDD 


| Termo                      | Tipo           | Agregado                 | Definição                                                                                                                                                                                                                          |
|----------------------------|----------------|--------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **SystemUser**             | Aggregate Root | Identity & Access        | Utilizador do sistema identificado por email único. Possui nome, telefone, estado (ativo/inativo), *security clearance* com data de expiração e data da última avaliação de competências. Ponto de entrada para gestão de acessos. |
| **user Id**                | Value Object   | Identity & Access        | Identificador único de um utilizador, baseado em UUID. Imutável.                                                                                                                                                                   |
| **Email**                  | Value Object   | Identity & Access        | Endereço de email válido de um utilizador. Deve pertencer a um domínio permitido. Imutável.                                                                                                                                        |
| **Name**                   | Value Object   | Identity & Access        | Nome completo do utilizador (primeiro nome + apelido). Imutável.                                                                                                                                                                   |
| **Phone Number**           | Value Object   | Identity & Access        | Número de telefone do utilizador. Imutável.                                                                                                                                                                                        |
| **Security Clearance**     | Value Object   | Identity & Access        | Credencial de segurança do utilizador com nível e data de expiração. Expira automaticamente. Imutável.                                                                                                                             |
| **User Role Assignment**   | Entity         | Identity & Access        | Atribuição de um papel (role) a um utilizador. Permite que no futuro um utilizador tenha múltiplos papéis.                                                                                                                         |
| **User Role**              | Enumeration    | Identity & Access        | Papel de um utilizador no sistema: `ADMIN`, `BACKOFFICE_OPERATOR`, `AIR_TRANSPORT_COMPANY_COLLABORATOR`, `PILOT`, `FLIGHT_CONTROL_OPERATOR`, `WEATHER_PERSON`.                                                                     |
| **Manufacturer**           | Aggregate Root | Backoffice Configuration | Fabricante de aeronaves e/ou motores. Identificado por nome e país. O par nome+tipo deve ser único.                                                                                                                                |
| **Manufacturer Id**        | Value Object   | Backoffice Configuration | Identificador único de um fabricante, baseado em UUID. Imutável.                                                                                                                                                                   |
| **Manufacturer Name**      | Value Object   | Backoffice Configuration | Nome do fabricante. Imutável.                                                                                                                                                                                                      |
| **Manufacturer Type**      | Enumeration    | Backoffice Configuration | Classificação do fabricante: `AIRCRAFT`, `ENGINE` ou `BOTH`.                                                                                                                                                                       |
| **Country**                | Value Object   | Backoffice Configuration | País identificado por código ISO e nome. Partilhado entre agregados como Value Object. Imutável.                                                                                                                                   |
| **Engine Model**           | Aggregate Root | Backoffice Configuration | Modelo de motor certificado para uso em aeronaves. O par nome+fabricante deve ser único. Contém dados de empuxo e eficiência de combustível.                                                                                       |
| **Engine Model Id**        | Value Object   | Backoffice Configuration | Identificador único de um modelo de motor, baseado em UUID. Imutável.                                                                                                                                                              |
| **Engine Type**            | Enumeration    | Backoffice Configuration | Tipo de motorização: `TURBOPROP`, `TURBOFAN`, `TURBOJET`, `RAMJET`, `ELECTRIC_PROPELLER`.                                                                                                                                          |
| **Thrust Value**           | Value Object   | Backoffice Configuration | Valor de empuxo em Newtons (N). Imutável. Usado para empuxo ao nível do mar parado e na velocidade de cruzeiro.                                                                                                                    |
| **Fuel Efficiency**        | Value Object   | Backoffice Configuration | Consumo específico de combustível por empuxo (TSFC), com valor e unidade. Imutável.                                                                                                                                                |
| **Aircraft Model**         | Aggregate Root | Backoffice Configuration | Especificação técnica de um modelo de aeronave. O par nome+fabricante deve ser único. Contém parâmetros físicos e lista de motores certificados. Deve ter pelo menos um motor certificado.                                         |
| **Aircraft Model Id**      | Value Object   | Backoffice Configuration | Identificador único de um modelo de aeronave, baseado em UUID. Imutável.                                                                                                                                                           |
| **Aircraft Type**          | Enumeration    | Backoffice Configuration | Classificação do modelo de aeronave: `PASSENGER`, `CARGO` ou `MIXED`.                                                                                                                                                              |
| **Weight**                 | Value Object   | Backoffice Configuration | Peso em quilogramas. Usado para MTOW, MZFW e peso vazio. Imutável.                                                                                                                                                                 |
| **Fuel Capacity**          | Value Object   | Backoffice Configuration | Capacidade de combustível em litros. Usada também como mínimo de combustível exigido à chegada. Imutável.                                                                                                                          |
| **Altitude Meters**        | Value Object   | Backoffice Configuration | Altitude em metros acima do nível do mar. Imutável.                                                                                                                                                                                |
| **Speed**                  | Value Object   | Backoffice Configuration | Velocidade em metros por segundo. Usada para velocidade de cruzeiro. Imutável.                                                                                                                                                     |
| **Area**                   | Value Object   | Backoffice Configuration | Área em metros quadrados. Usada para a área da asa. Imutável.                                                                                                                                                                      |
| **Aerodynamic Coeff**      | Value Object   | Backoffice Configuration | Coeficiente aerodinâmico adimensional (sustentação `Cl` ou arrasto `Cd`). Imutável.                                                                                                                                                |
| **Air Control Area**       | Aggregate Root | Backoffice Configuration | Área geográfica de controlo aéreo com código único, fronteiras geográficas válidas e mínimo de combustível exigido à chegada.                                                                                                      |
| **Area Id**                | Value Object   | Backoffice Configuration | Identificador único de uma área de controlo aéreo, baseado em UUID. Imutável.                                                                                                                                                      |
| **Area Code**              | Value Object   | Backoffice Configuration | Código único da área de controlo aéreo. Imutável.                                                                                                                                                                                  |
| **Geographic Boundary**    | Value Object   | Backoffice Configuration | Conjunto de coordenadas geográficas que definem a fronteira de uma área. Imutável.                                                                                                                                                 |
| **Geo Coordinate**         | Value Object   | Backoffice Configuration | Par de coordenadas geográficas (latitude, longitude). Partilhado entre agregados. Imutável.                                                                                                                                        |
| **Airport**                | Aggregate Root | Backoffice Configuration | Aeroporto identificado por códigos IATA (3 letras) e ICAO (4 letras) únicos mundialmente. Possui localização, elevação e pertence a uma área de controlo aéreo.                                                                    |
| **Airport Id**             | Value Object   | Backoffice Configuration | Identificador único de um aeroporto, baseado em UUID. Imutável.                                                                                                                                                                    |
| **Airport Name**           | Value Object   | Backoffice Configuration | Nome do aeroporto. Imutável.                                                                                                                                                                                                       |
| **IATA Code**              | Value Object   | Backoffice Configuration | Código IATA do aeroporto (3 letras). Único a nível mundial. Imutável.                                                                                                                                                              |
| **ICAO Code**              | Value Object   | Backoffice Configuration | Código ICAO do aeroporto (4 letras). Único a nível mundial. Imutável.                                                                                                                                                              |
| **Air Transport Company**  | Aggregate Root | Air Transport Company    | Companhia de transporte aéreo com nome e designadores IATA e ICAO únicos. Gere a sua lista de colaboradores ativos.                                                                                                                |
| **Company Id**             | Value Object   | Air Transport Company    | Identificador único de uma companhia de transporte aéreo, baseado em UUID. Imutável.                                                                                                                                               |
| **Company Name**           | Value Object   | Air Transport Company    | Nome da companhia de transporte aéreo. Imutável.                                                                                                                                                                                   |
| **IATA Designator**        | Value Object   | Air Transport Company    | Designador IATA da companhia (2 letras). Único. Imutável.                                                                                                                                                                          |
| **ICAO Designator**        | Value Object   | Air Transport Company    | Designador ICAO da companhia (2–3 letras). Único. Imutável.                                                                                                                                                                        |
| **Collaborator**           | Entity         | Air Transport Company    | Colaborador de uma companhia de transporte aéreo ou área de controlo. É também um utilizador do sistema. Tem email, nome e posição. Pode ser desativado.                                                                           |
| **Aircraft**               | Aggregate Root | Air Transport Company    | Aeronave concreta de um modelo específico, pertencente a uma companhia. Identificada por número de registo único. Tem configuração de cabine e estado operacional.                                                                 |
| **Aircraft Id**            | Value Object   | Air Transport Company    | Identificador único de uma aeronave, baseado em UUID. Imutável.                                                                                                                                                                    |
| **Aircraft Registration**  | Value Object   | Air Transport Company    | Número de registo único da aeronave. Imutável.                                                                                                                                                                                     |
| **Cabin Configuration**    | Value Object   | Air Transport Company    | Distribuição de lugares por classe (primeira, executiva, económica). O total não pode exceder a capacidade do modelo. Imutável.                                                                                                    |
| **Operational Status**     | Enumeration    | Air Transport Company    | Estado operacional de uma aeronave: `ACTIVE`, `MAINTENANCE`, `DECOMMISSIONED`. Uma aeronave descomissionada não pode ter voos criados.                                                                                             |
| **Flight Route**           | Aggregate Root | Air Transport Company    | Rota nomeada entre dois aeroportos, pertencente a uma companhia. Nome no formato `XX` + até 4 dígitos (ex: TP123), único no sistema. Pode ser desativada a partir de uma data futura.                                              |
| **Route Id**               | Value Object   | Air Transport Company    | Identificador único de uma rota, baseado em UUID. Imutável.                                                                                                                                                                        |
| **Route Name**             | Value Object   | Air Transport Company    | Nome da rota com formato validado (`XX` + até 4 dígitos). Imutável.                                                                                                                                                                |
| **Pilot Roster**           | Entity         | Air Transport Company    | Registo de um piloto na companhia, com lista de modelos de aeronave para os quais está certificado. Um piloto inativo não pode ter planos de voo atribuídos.                                                                       |
| **Flight Plan**            | Aggregate Root | Flight Plan              | Plano formal e completo de um voo, composto por uma ou mais pernas. Estado inicial `DRAFT`. Criado manualmente ou via importação de ficheiro DSL. Apenas planos `VALIDATED` podem ser executados.                                  |
| **Flight PlanId**          | Value Object   | Flight Plan              | Identificador único de um plano de voo, baseado em UUID. Imutável.                                                                                                                                                                 |
| **Flight Designator**      | Value Object   | Flight Plan              | Identificador único do voo no formato `xxn(n)(n)(n)(a)`: código da companhia (2 letras) + número (até 4 dígitos) + sufixo operacional opcional (1 letra). Imutável.                                                                |
| **Flight Type**            | Enumeration    | Flight Plan              | Tipo de voo: `REGULAR` (dias da semana fixos) ou `CHARTER` (data específica).                                                                                                                                                      |
| **Flight Plan Status**     | Enumeration    | Flight Plan              | Estado do plano de voo: `DRAFT`, `VALIDATED`, `REJECTED`, `ACTIVE`.                                                                                                                                                                |
| **Flight Leg**             | Entity         | Flight Plan              | Fase completa de um voo entre dois aeroportos consecutivos (uma descolagem e uma aterragem). Contém informações de partida, chegada, combustível e segmentos.                                                                      |
| **Departure Info**         | Value Object   | Flight Plan              | Informação de partida: aeroporto e data/hora agendada. Imutável.                                                                                                                                                                   |
| **Arrival Info**           | Value Object   | Flight Plan              | Informação de chegada: aeroporto e data/hora agendada. Imutável.                                                                                                                                                                   |
| **Fuel Load**              | Value Object   | Flight Plan              | Quantidade de combustível carregada, com valor e unidade (`KG` ou `LITRES`). Deve ser estritamente positiva. Imutável.                                                                                                             |
| **Fuel Unit**              | Enumeration    | Flight Plan              | Unidade de medida do combustível: `KG` ou `LITRES`.                                                                                                                                                                                |
| **Flight Segment**         | Entity         | Flight Plan              | Percurso linear entre dois pontos geográficos dentro de uma perna de voo. Tem coordenadas de início e fim (obrigatoriamente diferentes), slots de altitude e condições de vento.                                                   |
| **Altitude Slot**          | Value Object   | Flight Plan              | Slot de altitude permitido num segmento, com altitude e largura associada. Imutável.                                                                                                                                               |
| **Wind Condition**         | Value Object   | Flight Plan              | Condição de vento: ângulo de direção relativo ao Norte e velocidade em m/s. Partilhado entre agregados. Imutável.                                                                                                                  |
| **Weather Data Ref**       | Value Object   | Flight Plan              | Referência aos dados meteorológicos associados ao plano de voo: ID do registo, área e data. Imutável.                                                                                                                              |
| **Weather Record**         | Aggregate Root | Weather Service          | Registo meteorológico para uma área de controlo e data específica. Inclui temperatura, vento, densidade do ar e fonte dos dados. Pode ser introduzido manualmente ou importado em bulk.                                            |
| **Weather Id**             | Value Object   | Weather Service          | Identificador único de um registo meteorológico, baseado em UUID. Imutável.                                                                                                                                                        |
| **Temperature**            | Value Object   | Weather Service          | Temperatura em graus Celsius. Imutável.                                                                                                                                                                                            |
| **Air Density**            | Value Object   | Weather Service          | Densidade do ar em kg/m³. Varia com altitude e temperatura. Usada nos cálculos de física de voo. Imutável.                                                                                                                         |
| **Weather Source**         | Value Object   | Weather Service          | Fonte dos dados meteorológicos (nome e tipo do fornecedor externo). Permite agregar dados de múltiplas fontes. Imutável.                                                                                                           |
| **Simulation Run**         | Aggregate Root | Simulation               | Execução de uma simulação de controlo aéreo para uma área e intervalo de tempo. Agrega os voos incluídos, o limiar de segurança e o relatório gerado.                                                                              |
| **Simulation Id**          | Value Object   | Simulation               | Identificador único de uma simulação, baseado em UUID. Imutável.                                                                                                                                                                   |
| **Time Range**             | Value Object   | Simulation               | Intervalo de tempo da simulação (início e fim). Imutável.                                                                                                                                                                          |
| **Simulation Status**      | Enumeration    | Simulation               | Estado da simulação: `PENDING`, `RUNNING`, `COMPLETED`, `ABORTED`.                                                                                                                                                                 |
| **Simulation Report**      | Entity         | Simulation               | Relatório gerado no final de uma simulação. Contém total de voos, resultado de validação, eventos de violação e caminho do ficheiro exportado.                                                                                     |
| **Safety Violation Event** | Value Object   | Simulation               | Evento de violação de segurança: timestamp, IDs dos dois voos envolvidos e as respetivas posições geográficas no momento da violação. Imutável.                                                                                    |
| **Validation Result**      | Enumeration    | Simulation               | Resultado final da validação de uma simulação: `PASS` ou `FAIL`.                                                                                                                                                                   |
